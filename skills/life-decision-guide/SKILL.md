# 인생 결정: 《가성비 인생 가이드》를 찾아보고 답하기

## 이 skill이 하는 일

누가 구체적인 인생 문제를 어떻게 해야 하냐고 물으면, 먼저 《가성비 인생 가이드》에서 관련 항목을 찾아낸다. 그다음 책의 계산 방식대로 순서를 매겨 답한다.

**못 찾았으면 답하지 마라.** 답에 나오는 숫자, 법 조항, 결론은 하나하나 본문의 어느 항목으로 되짚어 갈 수 있어야 한다. 되짚을 수 없으면 책에 없다고 솔직히 말한다. 상식 수준의 판단은 줘도 되지만, 그건 상식이지 책 내용이 아니라고 밝힌다. 기억에 기대 숫자, DOI, 법 조항 번호를 채워 넣지 마라.

책은 얻어 내려는 것을 네 가지로 나눈다. 수명 · 시간과 에너지 · 돈 · 신체의 자유. **네 가지는 따로 계산하고 서로 환산하지 않는다.** "총사망률 12% 감소"와 "해마다 500위안 절약"은 같은 자로 잴 수 없다.

## 0단계: 당장 멈춰야 하는지부터 본다

- **지금 벌어지고 있는 응급상황**(쓰러져서 숨을 안 쉼, 대량 출혈, 화재, 익수, 감전, 중독, 뇌졸중이나 심근경색 증상): 먼저 120 / 119에 전화하라는 것과 현장에서 할 첫 동작을 말한다. 출처는 제13장이다. 가성비 얘기는 나중이다.
- **자살 생각, 더는 못 살겠다는 말이 나올 때**: 먼저 전국 심리지원 핫라인 12356을 알려 준다. 그다음 제1장과 제29장의 항목대로 말한다. 설득조로 분석하지 않고, 동기를 평가하지 않는다.
- **진행 중인 법적 절차**(이미 소환됨, 이미 구금됨, 이미 기소됨): 먼저 제8장의 해당 항목을 가리킨다. 책은 일반적인 기준만 주며, 개별 사건은 변호사를 찾아야 한다고 밝힌다.
- 나머지 경우는 아래 단계를 따른다.

## 1단계: 본문을 손에 넣는다

**로컬**: 현재 디렉터리나 상위 디렉터리에 `README.md`와 `book/01-일찍-죽지-않기.md`가 있으면 로컬 모드다. 바로 읽는다.

**원격**: 없으면 그때 가져온다. 책 전체가 1.3 MB라서 얕은 클론 한 번이 가장 편하고, 뒤에 나오는 명령도 모두 그대로 쓸 수 있다.

```bash
git clone --depth 1 https://github.com/eternity4719/HowToLiveBetter.git "${TMPDIR:-/tmp}/hltb"
```

git을 쓸 수 없으면 파일 단위로 가져온다(파일 이름의 중국어는 그대로 써도 된다).

```bash
curl -fsSL --compressed "https://raw.githubusercontent.com/eternity4719/HowToLiveBetter/main/book/02-不要慢慢死.md"
```

둘 다 안 되면 본문을 가져올 수 없다는 뜻이다. 사용자에게 사실대로 말하고, 기억에 기대 책 내용을 되풀이하지 마라.

## 2단계: 장을 찾는다

먼저 1~3개 장을 고른다. 저장소 루트 `README.md`의 "이 책이 답하려는 질문" 표를 읽는다. 한 장이 한 줄이고, 그 장이 무슨 질문에 답하는지와 `book/` 아래 해당 파일 이름이 적혀 있다. 사용자가 묻는 일과 맞춰 본다. 장이 늘거나 줄면 모두 그 표에 반영되므로, 여기에는 목록을 따로 두지 않는다.

장 파일은 `book/` 아래 있다. 파일 이름에 장 번호와 장 이름이 붙어 있어서 `ls book/`로도 전부 볼 수 있다.

장문 문서는 `docs/`에 있다. 결혼은 남는 장사인가, 가정용 비상장비 목록, 플랫폼을 하려면 어떤 인허가가 필요한가, 낯선 사람이 사고를 당했을 때 멈춰야 하나.

## 3단계: 항목을 건져 낸다

가장 큰 장 파일은 110 KB나 된다. 통째로 읽지 말고 키워드로 건져 낸다. Grep / Read 같은 도구가 있으면 도구를 쓰고, 셸만 있으면 명령을 쓴다.

```bash
grep -rn '^### ' book/ | grep -E '키워드1|키워드2'        # 어떤 항목 제목이 있는지 먼저 본다
grep -rn -B2 -A8 '키워드' book/08-법과-재산-지키기.md        # 본문에서 앞뒤 문맥과 함께 찾는다
sed -n '/^### 16\. /,/^### 17\. /p' book/08-법과-재산-지키기.md  # 번호로 항목 하나를 통째로 뽑는다
```

**뽑아낸 항목은 끝까지 다 읽어라.** 특히 "비고" 칸이 중요하다. 적용 대상, 논쟁, 예외가 전부 거기 적혀 있어서 제목만 읽으면 조건을 놓친다.

항목 하나는 이렇게 생겼다.

```markdown
### 5. 집에서 쓰는 소금을 저나트륨 소금(칼륨 소금)으로 바꾼다
<!-- 成本标签: 钱=少 时间=少 毅力=否 收益=中 口径=死亡率 -->
- 비용: 한 봉지에 몇 위안 더 비싸다
- 쉽게 말하면: ……죽을 확률이 약 12% 낮아진다……
- 효과: 뇌졸중 14% 감소, 심혈관 사건 13% 감소, 총사망률 12% 감소
- 근거 등급: A
- 출처: Neal B, et al. (2021). NEJM. https://doi.org/10.1056/NEJMoa2105675
- 비고: 논쟁. 신장 기능이 떨어진 사람, 칼륨 보존 이뇨제를 먹고 있는 사람은 쓰지 마라. ……
```

그 HTML 주석 한 줄은 기계가 읽는 비용 태그다. 돈(钱) 0/少(적음)/多(많음), 시간(时间) 少/中/多, 의지력(毅力) 否(아니오)/些(약간)/是(예), 효과(收益) 大(큼)/中(중간)/小(작음), 기준(口径) 死亡率(사망률)/金钱(돈)/时间(시간)/自由(자유).

## 4단계: 순서를 매긴다

순서는 책의 계산법대로 매긴다. 감으로 하지 마라.

1. 등급 계산법은 저장소 루트의 `index.html`이 기준이다. 기억으로 쓰지 말고, 그 자리에서 두 줄을 뽑아 그대로 계산한다.

   ```bash
   grep -n 'COST_W = \|e\.ratio = ' index.html
   ```

   앞줄은 세 가지 비용의 등급별 가중치다. 비용 점수 = 돈 + 시간 + 의지력 세 항목의 합이다. 뒷줄은 효과 크기와 비용 점수를 합쳐 "매우 높음 / 높음 / 보통" 중 어디에 떨어지는지 정한다.
2. 파일 단위로 본문만 curl로 받아서 `index.html`이 없으면, 가성비 등급을 말하지 않는다. 대신 효과 크기와 비용 태그 세 개를 그대로 늘어놓고 사용자가 직접 따져 보게 한다.
3. 먼저 가성비 순, 같은 등급 안에서는 근거 등급 A > B > C 순, 그다음 사용자 상황에 얼마나 들어맞는지 순이다.
4. **기준이 다른 항목끼리는 순서를 매기지 않는다.** 돈을 얻는 것과 수명을 얻는 것은 따로 나열하고 각자 정렬한다.
5. "보통"이 하지 말라는 뜻은 아니다. 그 비용을 사용자가 직접 따져 봐야 한다는 뜻일 뿐이다. 가성비는 저자의 판단이라서 책 자신의 기준으로는 C등급밖에 안 되고, 근거 등급과는 별개다.

## 5단계: 답을 어떻게 쓰나

순서를 매긴 뒤 이 구조로 쓴다.

1. **한 줄 결론**: 이 일이 남는 장사인지, 해야 하는지, 첫걸음은 뭔지.
2. **먼저 할 것들**(3~7개, 위의 순서대로). 항목마다 한 줄에서 세 줄. 동작(동사로 시작), 무엇을 쓰는지, 무엇을 얻는지, 근거 등급, 출처. 출처는 "제8장 17번(차용증과 보증)"처럼 쓰고, 괄호 안의 말은 항목 제목에서 가져와서 사용자가 직접 찾아볼 수 있게 한다.
3. **하지 말 것 / 안 해도 되는 것**: 책이 할 가치가 없다고 분명히 했거나 반대 근거가 있는 것은 따로 모은다.
4. **책에 없는 것**: 사실대로 말한다. 상식을 책 내용인 척하지 않는다.
5. 필요하면 다시 볼 시점을 한마디 덧붙인다. 언제 다시 살펴볼지, 어떤 신호가 보이면 생각을 바꿀지.

쓸 때 지킬 것:

- **누구에게 돌아가는지 분명히 한다.** 책은 수혜자를 네 단계로 나눈다. 그 이득이 나에게 돌아올 가능성이 높은 순서로 ① 나 자신, ② 배우자와 직계가족, ③ 친구·동료와 그 밖의 친척, ④ 낯선 사람이다. ④에 해당하는 얘기(낯선 사람 구하기, 남의 보증 서기, 남 대신 송금하기)를 쓸 때는 이득과 함께 위험한 면도 쓴다. 덤터기 쓰기, 사건에 휘말리기, 보복당하기. 좋은 점만 써서도 안 되고, 무조건 모른 척하라고 써서도 안 된다.
- **"법이 당신 편"인 일은 과정 비용까지 함께 말한다.** 결과만 말하고 과정을 빼면 승소율을 효과로 착각하게 된다. 소송을 해야 하는지, 대략 얼마나 걸리는지(1심 일반 절차는 6개월부터, 연장 가능. 간이 절차는 3개월), 변호사비는 누가 내는지(변호사비는 소송비용에 들어가지 않고, 패소한 쪽이 부담하는 비용에도 포함되지 않는다) 설명한다.
- **숫자는 항목에서 그대로 옮기고** 하나도 바꾸지 않는다. 항목에 신뢰구간, 대상 인구, 연도가 적혀 있으면 함께 남긴다. HR, RR, OR 같은 표기 옆에는 "약 28% 낮다"처럼 그 자리에서 풀어 쓰되 원래 값은 지우지 않는다. 항목에 없는 숫자, 증상, 기전 해석은 일절 보태지 않는다.
- **쉬운 말로**: 전문 교육을 받지 않은 어른이 한 번에 읽고 이해할 수 있게 쓴다. 전문 용어는 그 자리에서 일상어로 한 번 풀어 준다. 법 조항은 "어떤 결과를 떠안게 되는지, 어떻게 해야 하는지"로 풀어낸다. 출처 칸은 원래대로 줘서 확인할 수 있게 한다.
- **말투는 절제한다.** 훈계하지 않고 느낌표를 쓰지 않는다. 사용자가 권고대로 안 하는 건 그 사람 일이니 쫓아다니며 설득하지 않는다. 원문 규칙은 간체 중국어로 쓰라고 한다.
- **정책은 바뀐다.** 제7, 19, 21, 24, 31, 32장의 금액, 기한, 명단에는 본문에 기준 날짜가 적혀 있다. 답에 그 날짜를 함께 적고, 공식 경로에서 직접 확인하라고 일러 준다.
- "논쟁" 표시가 붙은 항목은 반대 근거도 한마디 한다. "TODO 확인 필요"가 붙은 것은 결론으로 쓰지 않는다.
- 즈후(知乎), 위챗 공식계정, 소후(搜狐) 같은 2차 전달은 인용하지 않는다. 항목 "출처" 칸에 이미 있는 링크만 준다.

## 한계

이 책은 일반적인 기준을 줄 뿐, 의사·변호사·회계사를 대신하지 않는다. 구체적인 병세, 구체적인 사건, 구체적인 세금 문제는 책의 항목대로 방향과 누구를 찾아가야 하는지만 알려 주고, 전문가 대신 판단하지 않는다. 개인 맞춤 투자 조언은 하지 않는다.

책의 관점은 저자의 것이고, 가성비 순으로 정렬한 것도 저자의 판단이다. 사용자가 어떤 항목에 동의하지 않으면 책의 근거를 보여 주는 것으로 충분하다. 논쟁하지 않는다.
